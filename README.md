# ToDo Lite（Windows 用）

Google ToDo（Google Tasks）と、ほぼリアルタイムに同期する Windows 用の軽量な ToDo アプリです。exe 1 つで動きます。

このリポジトリには、配布する exe と、確認用のハッシュのファイル・署名のファイルだけを置いています（ソースは置いていません）。
最新の版は [Releases](https://github.com/almondtiara/todolite-releases/releases/latest) にあります。

## できること

- 複数のリストを列に並べて、一度に見渡せます（列の並び・幅・ピン留め・ハイライトは PC ごとに覚えます）
- タスクの追加・編集・完了・サブタスク・予定日・並べ替え（ドラッグ&ドロップ）・元に戻す（Ctrl+Z）
- Google ToDo との同期（スマホの Google ToDo アプリと同じデータ）。オフラインの間の変更は、つながったときに送ります
- トレイに常駐、常に手前に表示
- Windows にサインインしたら起動（設定のメニューで切り替え。既定はオフ。下の「サインインしたら起動する」）
- タスクバーにピン留め（v0.4.2 から。下の「タスクバーにピン留めする」）
- 表示サイズ（画面の拡大・縮小。67〜200%。v0.5.0 から。下の「表示サイズを変える」）
- 左の細いレールに、リストの追加・アカウント・設定のボタンをまとめ、リストを広く見せます（v0.6.0 から。下の「画面の左のレール」）
- レールを広げると出るリストの名前の一覧から、そのリストへすぐ移動できます（v0.7.0 から。下の「画面の左のレール」）
- 会社などのプロキシ: Windows のプロキシの設定（手動・自動構成スクリプト・自動検出）に従います。
  認証を求めるプロキシには、ログイン中の Windows のアカウントで認証します
  - 手動の設定と、https の自動構成スクリプトが選んだプロキシには、自動で認証します
  - http の自動構成スクリプトや自動検出で見つけたプロキシには、初めてのときにウィンドウの上部の帯で
    「このプロキシを信頼しますか？」と確かめてから認証します（偽のプロキシに Windows の認証を渡さないため）
  - 信頼は、そのネットワークとプロキシの出どころに結び付けて PC ごとに覚えます。別のネットワークでは、もう一度確かめます
  - 名前の短いプロキシや、ネットワークを確かめられないとき（ゲートウェイの無い VPN など）は覚えずに、起動している間だけ信頼します
- 自動更新（下の「自動更新」）

動く環境: Windows 10 / 11（64 ビット）。ほかに入れるもの（ランタイムなど）はありません。

## 最初の入れ方

1. **exe を取る:** [Releases の最新版](https://github.com/almondtiara/todolite-releases/releases/latest) を開き、`todolite-rs.exe` をブラウザで取ります。
   - 取った exe が壊れていないかを確かめるときは、同じ所の `todolite-rs.exe.sha256` の値と、PowerShell の
     `Get-FileHash .\todolite-rs.exe` の値（大文字・小文字の違いは気にしなくてよい）を比べます。
   - 同じ所の `todolite-rs.exe.sig`（電子署名）は、アプリが自動更新のときに確かめるものです（最初に手で入れる exe は、
     アプリがまだ無いので確かめられません）。
2. **置く:** 自分で書き込めるフォルダ（例: `C:\Apps\ToDoLite`）に置きます。
   - `C:\Program Files` の下は避けてください（自動更新で exe を入れ替えられません）。
   - **OneDrive・Box・Dropbox などの同期フォルダや、ネットワークの場所には置かないでください。** ローカルのフォルダ
     （例: `%LOCALAPPDATA%\Programs\ToDoLite` や `C:\Apps\ToDoLite`）に置きます。理由:
     - exe の隣の `data\` にあるタスクの内容（`cache.json`。暗号化していません）が、同期先に送られます
     - 同期中のファイルのロックで、保存や自動更新に失敗することがあります
     - Windows がタスクバーのピン留めの対象にしないことがあります
     - サインインしたときの起動で、同期フォルダがまだ使えないことがあります
3. **初めて起動する:** exe をダブルクリックします。「Windows によって PC が保護されました」（SmartScreen）と出たら、
   **「詳細情報」→「実行」** を押します（Windows のコード署名（Authenticode）をしていないため出ます。2 回目からは出ません。
   下の「自動更新」の署名は、アプリが自分で確かめる別の仕組みです）。
4. **client_secret.json を置く:** Google Cloud で作った OAuth のクライアント（種類は「デスクトップ アプリ」）の JSON を、
   exe と同じフォルダに `client_secret.json` という名前で置きます（ダウンロードしたときの `client_secret_….json` のままでも読めます）。
5. **ログインする:** 左のレールのクラウドのボタン →「Google にログイン」。ブラウザで Google のアカウントを選んで許可します
   （v0.5.0 までは、上の一段の雲のボタンでした）。

注意:
- **テストモード**（既定でオン）: Google に書き込むのは、名前が「テスト」で始まるリストだけです。設定のメニューでオフにします。
- データは exe の隣の `data\` に保存されます（`cache.json`・`settings.json`・`queue.json`・`token.bin`・`sync.log`）。
  `token.bin` は、その PC のその Windows のユーザーだけが読める形で暗号化しています。

## サインインしたら起動する

- **オンにする:** 設定（⚙）のメニューの「Windows にサインインしたら起動」を押します（チェックが付きます）。もう一度押すとオフになります。
  - サインインしたときは、いつもどおりウィンドウを出して始まります（「トレイ常駐」がオンでもオフでも同じです。v0.4.0 では、トレイ常駐がオンなら
    トレイに入った状態で始まっていましたが、v0.4.1 からウィンドウを出すようにしました）。
  - エクスプローラーが再起動したときは、トレイのアイコンを出し直します。ウィンドウをトレイに隠している間にトレイのアイコンを出せなかったときは、ウィンドウを出します。
    トレイにアイコンが無いときは × を押してもトレイには隠さずに最小化し、画面の下に「トレイのアイコンが無いので、最小化しました（終わるときは ⚙ の「トレイ常駐」を外してから × を押してください）」と出ます。
  - すでに ToDo Lite が動いているときは、サインインの起動は何もせずに終わります。
- **仕組み:** Windows の「自分のアカウントのスタートアップ」の登録（レジストリの `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` の
  `ToDoLite`）に、この exe の場所を書きます。管理者の権限は要りません。オフにすると消します。
- **注意:**
  - **exe を別のフォルダへ動かしたとき:** 動かした先の exe を一度起動すると、登録がその場所に直ります（設定は exe の隣の `data\` にあるので、
    `data\` ごと動かしてください）。起動のたびに直すのは、登録が無い・読めないとき、または登録の指す exe がもう無いときだけです。
  - **`data\` ごと写して、2 つ目の ToDo Lite を置いたとき:** 元の exe が残っている間は、2 つ目を起動しても登録は元の exe のままです
    （自動では取りません）。2 つ目を起動するたびに、画面の下に「サインイン時の起動は、別の場所の ToDo Lite に登録されています。
    ⚙ で一度オフにしてからオンにすると、こちらになります」と出ます。2 つ目をサインインで起動したいときは、2 つ目の ⚙ のメニューで
    「Windows にサインインしたら起動」を一度オフにしてからオンにしてください（登録が 2 つ目に移ります）。
  - **Windows の設定で止めているとき:** 「設定 → アプリ → スタートアップ」（またはタスク マネージャーの「スタートアップ アプリ」）で ToDo Lite を
    オフにしていると、登録があっても起動しません。そのときは、オンにしたときと起動したときに、画面の下に
    「Windows の設定で、スタートアップが止められています（設定 → アプリ → スタートアップ）」と出ます。そちらでオンに戻してください。
  - **登録できないとき**（会社の PC のポリシーなど）: 「自動起動を設定できませんでした（Windows のエラー …）」と出て、設定は変わりません。
  - **やめるとき・アプリを消すとき:** 先にメニューでオフにしてから exe を消してください（オフにしないで exe を消すと、登録だけが残ります。
    残ったときは「設定 → アプリ → スタートアップ」でオフにするか、同じ場所に exe を戻して起動し、メニューでオフにします）。
  - 別のフォルダに置いた 2 つ目の ToDo Lite でオフにしても、1 つ目の登録は消しません（登録はオンにしたほうの exe のものです）。
    そのときは「この場所の登録はありません（別の場所の ToDo Lite の登録が残っていて、サインインではそちらが起動します）」と出ます。

## タスクバーにピン留めする

- ToDo Lite が動いている間に、タスクバーのボタンを右クリック →「タスクバーにピン留めする」を押します（v0.4.2 から、自動更新のあとや
  サインインしたときに起動した ToDo Lite にも、ピン留めのための情報を Windows に知らせるようにしました）。ピン留めしたアイコンからは、
  いつもどおり（引数なしで）起動します。
- **ピン留めは、動いている ToDo Lite のタスクバーのボタンからしてください。** エクスプローラーで exe を右クリックしたり、ショートカットから
  ピン留めしたりすると、Windows にはアプリの ID の無いピン留めになり、動いているウィンドウが別のボタンに並びます。
  そうなったときは、そのピン留めを外して、動いている ToDo Lite のボタンからピン留めし直してください。
- **メニューに「タスクバーにピン留めする」が出ないとき:** exe を OneDrive・Box・Dropbox などの同期フォルダに置いていないか確かめ、
  置いているなら上の「置く」のとおり、`data\` ごとローカルのフォルダへ動かしてから起動し直してください（同期フォルダの exe では、
  Windows がピン留めの対象にしないことがあります）。
- **v0.4.1 までにピン留めしたとき:** v0.4.2 に更新したあと、ピン留めしたアイコンを一度外して（右クリック →「タスクバーからピン留めを外す」）、
  動いている ToDo Lite のボタンからピン留めし直してください（v0.4.2 から Windows に知らせるアプリの ID が変わったため、外さないと、
  ピン留めのアイコンと動いているウィンドウが別々に並びます）。
- **exe を別のフォルダへ動かしたとき**も、ピン留めし直してください（置き場所の違う ToDo Lite は、別のアプリとして扱います）。

## 画面の左のレール

v0.6.0 から、上の一段のボタンと下のステータスバーをやめて、ウィンドウの左の端の細い縦の帯（レール）にまとめました。

- **＋（上）:** リストを追加します。
- **「テスト」の印:** テストモードの間だけ出ます（ウィンドウの高さがとても低いときは出しません）。
- **クラウド:** アカウントのメニュー（Google にログイン・今すぐ同期（F5）・テストモード・ログアウト）を開きます。
  同期の状態は、問題のときだけアイコンに印を付けます:
  - 送っている・取りそろえている間は、回る矢印の形に変わります（動きはしません）
  - **オレンジの三角:** オフライン・要ログイン・ブラウザでのログイン待ち
  - **赤い丸に白い「!」:** 同期しない設定・データを保存できない・サーバーの失敗で再送を待っている
  - データを保存できなかったときは、画面の下の中央にも「保存に失敗しました（理由）」と 1 回出ます（失敗が続いている間は繰り返しません）。
- **⚙（下）:** 設定のメニューを開きます（トレイ常駐・サインインしたら起動・常に手前・ピン留め列・テストモード・表示サイズ・更新を確認）。
- メニューはボタンの右に開きます。
- **マウスを少し乗せると:** レールがリストの上に重ねて広がり、ボタンの名前と同期の状態（「同期済み 12:03」など）が出ます。マウスを離すとすぐ戻ります。
  リストの列は動きません。リストへ向かってレールの上を通り過ぎただけでは広がりません。
- **リストの一覧（v0.7.0 から）:** 広げたレールの ＋ の下に、リストの名前が画面の並び（左の列から右の列へ、列の中は上から下）で出ます。
  ピン留め列を出しているときは、その位置に「ピン留め」が入ります。
  - 名前を押すと、レールが閉じて、そのリストが全部見える所まで画面が動き（すでに見えていれば動きません。画面より長いリストは上の端に合わせます）、
    リストが青い枠で 1.5 秒ほど目立ちます。
  - ウィンドウの幅が狭く、上のボタンでリストを切り替えているときは、押したリストに切り替わります。
  - リストが多くて入りきらないときは、一覧の上でマウスホイールを回すとスクロールします。
- **知らせ:** 「完了を取り消しました」などの少しの間だけの知らせは、画面の下の中央に出て、約 4 秒で消えます。
  ブラウザでログインしている間は「ブラウザでログインしてください ［取り消す］」が、終わるまで出ています。
- **常に手前:** 設定のメニューか、トレイのアイコンのメニュー、F12 で切り替えます（F12 のときは「常に手前: オン」などと出ます）。

## 表示サイズを変える

画面全体（文字・ボタン・行の高さなど）を、ブラウザーの拡大と同じ段階（67・75・80・90・100・110・125・150・175・200%）で大きく・小さくできます。
ウィンドウの大きさは変わらず、ウィンドウに入る列や行の数が変わります。

- **Ctrl + マウスホイール:** 上へ回すと拡大、下へ回すと縮小（1 ノッチで 1 段）。Ctrl を押している間は、ホイールでスクロールしません。
- **Ctrl + +:** 拡大（日本語キーボードでは `Ctrl + ;`（「+」のキー）でも、`Ctrl + Shift + ;` でも。テンキーの `+` でも）。
- **Ctrl + -:** 縮小（`-` のキーか、テンキーの `-`）。
- **Ctrl + 0:** 100% に戻す（`0` のキーか、テンキーの `0`）。
- **設定（⚙）のメニュー →「表示サイズ（今は N%）」:** 段階を選ぶか、「拡大」「縮小」「100% に戻す」を押します。
- タスクの名前を編集している間も使えます。日本語入力で変換している間（確定していない文字がある間）は、キーの操作は入力のほうに使います。
- 変えると、画面の下に「表示サイズ: 110%」と出ます。いちばん大きい（200%）・小さい（67%）ときは、それ以上は変わりません。
- 表示サイズは PC ごとに覚え（`data\settings.json`）、次の起動でも同じ大きさで始まります。Ctrl + Z では戻りません。
- 設定（⚙）などのメニューは、Windows の大きさのままです（表示サイズでは変わりません）。

## 自動更新

- **確かめる時:** 起動して 10 秒後と、24 時間ごと。設定（⚙）のメニューの「更新を確認」で、すぐにも確かめられます。
- **知らせ方:** 新しい版があると、ウィンドウの上部に帯が出ます（「新しい版 v0.3.0 があります（今は v0.2.0）」）。
  トレイにいるときは、トレイのアイコンのツールチップにも出ます。
  - **［更新して再起動］:** 新しい版を取り、確かめてから入れ替えて、新しい版で起動し直します（下の流れ）。
  - **［あとで］:** その版について、24 時間は帯を出しません。
- **入れ替えの流れ:**
  1. 編集中のものを確定し、データと送る待ちの変更を保存します（送る待ちの変更は、新しい版が送ります）。
  2. `todolite-rs.exe` を exe の隣に `todolite-rs.exe.new` として取ります（進み具合は、上の更新の帯の文の後ろに出ます）。
  3. 大きさと SHA-256 を、同じ版のハッシュのファイルと比べます。続けて、電子署名（`todolite-rs.exe.sig`）を、
     アプリに埋め込んである公開鍵で確かめます。署名は「ファイル名・版の番号・exe の SHA-256」に付けてあり、アプリは
     その版の番号と、取った exe から計算した SHA-256 で確かめます。どちらかが合わなければ捨てて、理由（「署名が確かめられません」など）を出します。
  4. 今の exe の名前を `todolite-rs.exe.old` に変え、`.new` を `todolite-rs.exe` にして、新しい版を起動します。
  5. 新しい版が起動できたら `.old` を消し、「v0.3.0 に更新しました」と出します。
     起動できなかったときは元の版に戻し、今のアプリを続けます。
- **exe の隣に書き込めないとき**（`C:\Program Files` に置いた場合など）は、理由が出ます。手で更新してください（下）。
- **安全のために:**
  - ダウンロードは https だけで、通信するのは `api.github.com`・`github.com`・`objects.githubusercontent.com`・
    `release-assets.githubusercontent.com` だけです。ほかの場所へのリダイレクトは追いません。
  - 取った exe は、同じ版のハッシュのファイル（SHA-256）と比べてから使います。壊れた・途中で切れたダウンロードは使いません。
  - さらに、電子署名（ECDSA P-256）を、アプリに埋め込んである公開鍵で確かめてから使います。署名するのは次の文（ASCII、改行は LF、
    最後の行も LF）で、`todolite-rs.exe.sig` は、この文の SHA-256 への署名を base64 にした 1 行です:

    ```
    todolite-release-v1
    file=todolite-rs.exe
    tag=vX.Y.Z
    sha256=<exe の SHA-256 の小文字の 16 進>
    ```

    署名の鍵は、配布する人の PC にだけあり、このリポジトリにはありません。このリポジトリ（GitHub のアカウント）が
    乗っ取られて偽の exe が置かれても、署名が合わないので、アプリは入れ替えません。署名のファイルが無い版も使いません。
    署名は版の番号にも付けてあるので、過去に正しく署名した古い版の exe を、新しい版の番号で置き直されても、入れ替えません
    （古い版に戻されることはありません）。
  - 署名の公開鍵が入っていない版のアプリは、新しい版を見つけても自動では更新せず、
    「署名の鍵が入っていない版なので、自動更新は使えません」と出します（手で更新してください）。
  - 更新の確認で送るのは、アプリの名前と版（User-Agent）だけです。Google のデータやトークンは送りません。
- **手で更新するとき:** アプリを終了し（トレイのアイコンの右クリック →「終了」）、最新の版の `todolite-rs.exe` で、
  今の exe を置き換えます。`data\` はそのまま使えます。

## 困ったとき

- 通信の記録は `data\sync.log` にあります（同期・プロキシ・自動更新・サインインしたら起動の登録。トークン・タスク名・プロキシのアドレス・exe の場所は書きません）。
- 同期できないとき: 左のレールのクラウドにマウスを乗せて出る同期の状態（「オフライン」「ログインが必要です」など。トレイのアイコンのツールチップにも出ます）と、
  `sync.log` の `net` の行（プロキシの方式と失敗）を見てください。
